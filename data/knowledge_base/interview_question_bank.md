# Behavioral Questions

- Tell me about a project where you had to learn a new tool quickly.
- Describe a time you debugged a difficult issue.
- How do you handle unclear requirements?

# Technical Questions

- Explain a machine learning project you built.
- How would you validate a dashboard metric?
- What is a REST API and how have you used one?

# Project Deep Dive

- What tradeoffs did you make in your recommendation system?
- How did you clean and validate the sales dataset?
- How did your Flask app store and retrieve data?
- If you rebuilt this project today, what would you change first?
- Which part of this project took the longest, and why?

# Machine Learning Concepts

- How do you tell whether a model improvement is real and not noise?
- What is overfitting, and how did you detect it in your own work?
- Why split data into training, validation, and test sets?
- How would you choose between precision and recall for a given task?
- What does a confusion matrix tell you that accuracy does not?

# Data Analysis Concepts

- How would you check whether a dashboard metric is trustworthy?
- What do you do when two data sources disagree?
- How do you handle missing values, and when is dropping rows wrong?
- Explain the difference between correlation and causation using your own analysis.
- How would you summarize a technical finding for a non-technical audience?

# Software Engineering Concepts

- Walk through how you would debug a failing API endpoint.
- What is the difference between a GET and a POST request?
- How do you decide what belongs in a unit test?
- Why use version control branches rather than committing to main?
- How would you approach reading an unfamiliar codebase?

# SQL And Databases

- Write a query that finds the top five records by a computed total.
- What is the difference between an inner join and a left join?
- When would an index help, and when might it not?
- How would you find duplicate rows in a table?

# Questions To Ask The Interviewer

- What does a successful first month look like for this intern?
- How is work reviewed, and who would I be learning from?
- What tools does the team use day to day?
- What kinds of problems is the team working on this quarter?
